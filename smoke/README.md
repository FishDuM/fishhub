# 🚀 FishHub 全链路高并发压力测试套件 (Smoke Stress Suite)

一套开箱即用、自包含、高便携性的全链路高并发压力测试工具包。支持从 GitHub 下载后**在任意电脑上一键双击运行**，全方位压测 FishHub 所有核心微服务链路的吞吐量（QPS/TPS）、延迟分布（P50/P90/P95/P99）、多级缓存与高并发最终一致性。

---

## 🌟 核心特性

1. **一键双击启动**：Windows 用户直接在 `smoke/` 目录下双击 `run_smoke_stress.bat` 即可拉起测试，无需记忆复杂指令；Linux/macOS 用户执行 `./smoke/run_smoke_stress.sh`。
2. **零数据前置依赖与自动自愈**：无需提前向数据库导入假数据，压测引擎采用“**自动预热活跃用户 -> 动态生成 Snowflake 笔记 -> 提取真实 ID 注入互动流**”的闭环自愈模式，空库也能 100% 跑通。
3. **全链路覆盖 (7 大核心场景)**：
   - 🛡️ **用户认证域**：验证码并发获取、用户并发解析/注册、主页资料高频查询、批量用户查询；
   - 👥 **社交关系域**：高并发关注风暴、取关风暴、关注列表游标分页、粉丝列表游标分页；
   - 📝 **笔记与内容域**：图文笔记批量发布、热点笔记详情读取（多级缓存与单飞防击穿验证）、发现流/频道流高频拉取；
   - ❤️ **互动与点赞域**：高并发笔记点赞/取消点赞、收藏/取消收藏（验证 Redis + RocketMQ 削峰）；
   - 💬 **评论与热度域**：一级评论发布、二级子评论回复、评论流热度分页排序、评论点赞；
   - 🔍 **全文检索域**：笔记多维度全文检索、用户关键词检索；
   - 📊 **计数聚合域**：笔记多维计数聚合拉取、用户多维计数拉取；
   - 🌪️ **混合大促域 (E2E Heavy Load)**：60% 读 + 20% 互动 + 15% 评论 + 5% 发布的高拟真混合大促流量冲击。
4. **高精度指标分析**：实时统计总请求数、成功率、QPS、Min/Avg/P50/P90/P95/P99 延迟，自动输出对齐的美化 ASCII 彩色榜单与 Markdown 报表。
5. **安全分批清理机制**：支持压测后自动提醒或随时一键清理，采用 `LIMIT 500` 分批物理清除与 Redis 定向清除，绝不打挂数据库，绝不影响原有业务数据。

## 🚀 快速开始

### 方式 1：Windows 一键双击（最推荐）
进入 `smoke/` 目录，双击：
```
run_smoke_stress.bat
```
控制台将自动弹出中文交互式菜单，可自由选择标准压测、极速压测、极限暴力测试、**自定义并发与轮次**或指定业务域单测。

---

### 方式 2：Linux / macOS 终端一键运行
```bash
chmod +x smoke/run_smoke_stress.sh
./smoke/run_smoke_stress.sh
```

---

### 方式 3：Python 命令行自定义参数运行
```bash
# 全链路标准压测 (默认 50 并发线程, 单场景 200 轮)
python smoke/run_all.py

# 自定义高并发与轮次
python smoke/run_all.py -c 100 -r 500

# 仅压测指定场景 (如仅压测场景 3 笔记互动域 与 场景 7 混合链路)
python smoke/run_all.py -s 3,7 -c 80 -r 300
```

## 🧹 压测数据一键清理 (Data Cleanup)

为了防止压测在大并发下产生海量数据并在数据库与 Redis 中留下脏数据，套件提供了**三级分批安全清理机制**：

1. **压测结束自动提醒**：每次压测跑完后，控制台会自动询问：
   ```text
   >>> 是否立即自动清理本次压测产生的测试数据 (Y/n, 默认 Y): 
   ```
   直接按回车即可自动秒级安全出清。
2. **独立一键清理工具**：随时双击 `smoke/clean_data.bat` 或在主菜单中选 `[10]`，即可调起清理器：
   - **业务层级**：自动调用 `/note/delete`、`/comment/delete`、`/relation/unfollow` 进行优雅出清；
   - **数据库层级**：采用 `DELETE ... LIMIT 500` **分批分块循环删除与微量休眠**，消除长事务锁表与 IO 洪峰，精准物理清除沙箱测试数据（`phone LIKE '1380000%'`、`title LIKE '压测%'`、`user_id >= 9000000`）；
   - **Redis 缓存层级**：定向清除压测产生的测试 Key 与临时 Session，完全不影响正常业务数据。

## ⚙️ 环境变量自定义配置

若后端服务部署在不同服务器或修改了端口，可通过环境变量覆盖：

| 环境变量 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `FISHHUB_GATEWAY_URL` | `http://127.0.0.1:8000` | 网关统一访问入口 |
| `STRESS_CONCURRENCY` | `50` | 默认并发线程数 |
| `STRESS_ROUNDS` | `200` | 默认单场景请求轮次 |
| `STRESS_TIMEOUT` | `10.0` | 单次 HTTP 请求超时时间（秒） |
| `MYSQL_PASSWORD` | `3057433102` | 本地数据库密码（用于清理工具） |
| `REDIS_PASSWORD` | `3057433102` | 本地 Redis 密码（用于清理工具） |

## 📊 报表输出与查看

每次压测执行完毕后：
1. **控制台** 即时渲染高可读性且支持中文字符精准对齐的 ASCII 成绩总榜（包含 QPS、成功率、P50/P95/P99 延迟分位数）；
2. **本地文件** 自动保存至 `smoke/reports/smoke_report_<时间戳>.md`，方便作为压测基准沉淀与汇报。
